# Capstone 3 - Analysis with Power BI
### Emporium South Region Sales Report 

---
## Project Overview

This project analyzes four years of sales performance (2022-2025) for **EmporiUm**, a virtual student bookstore. The report was built for the **South Region**, covering **Florida**, **South Carolina**, and **Texas**.

The Power BI report is designed to support regional directors, territory managers, and store managers in making informed business decisions by surfacing sales trends, category performance, state-level comparisons, and top-selling book titles.
